# Growing Rio

Brazilian management / narrative simulation prototype built with Godot. `DA LATA` is the campaign endgame storyline.

## Engine
Godot **4.7.2 stable**.

## Run
1. Open this folder in Godot 4.7.2.
2. Run the project (`F6/F5` depending on editor workflow; main scene is configured).
3. Play through the 30-day vertical slice.

## Current loop
Care for the grow space → advance days → harvest → choose a market channel → manage Cash / Heat / Reputation / Influence.

## Scope note
Cultivation, illicit-market activity and politics are intentionally modeled at an abstract strategy-game level. This project is not intended to provide real-world operational instructions.

## Synthesis for DA LATA

The grow room should use the references to push the already-accepted DA LATA grammar toward:

- **camera:** orthographic/isometric three-quarter cutaway;
- **scale:** miniature / model-set / toy-diorama;
- **geometry:** simple but deliberate low-poly masses with strong silhouettes;
- **density:** compact modular clusters, not empty blockout planes;
- **lighting:** cool/dark architectural envelope + warm localized practical pool;
- **materials:** matte/rough stylized concrete, plaster, dark metal, teal, warm wood, terracotta and foliage;
- **depth:** readable foreground/midground/background layers; subtle depth cues only when Web-safe;
- **UI relationship:** scene remains readable beneath minimal portrait UI rather than competing with it.

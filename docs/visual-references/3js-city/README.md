# CENA-021 / 3JS-004 — City visual references

## Purpose
Reference-only research for the next DA LATA visual slice: a fictional **Cidade** scene that inherits the accepted Grow Room / Mercado Three.js grammar without reproducing a real Rio de Janeiro neighborhood, landmark or map.

No image from these sources is a runtime asset. No source file is copied into the repository.

## Reference questions
- How can steep relief and dense low-rise massing read clearly in a compact orthographic miniature?
- How can vegetation breaks, retaining edges and occasional taller volumes create district contrast without literal geography?
- How can a city scene remain legible behind portrait UI without becoming a map or navigation simulator?

## DA LATA synthesis
The runtime target must remain original and fictional:
- compact orthographic hillside-city diorama;
- three readable elevation bands rather than a literal street network;
- repeated low-rise blocks with a few restrained taller silhouettes;
- vegetation / retaining-wall breaks between district clusters;
- dark concrete/metal envelope with warm plaster, terracotta and teal accents inherited from the accepted style lock;
- one restrained warm practical cluster against cool ambient/key lighting;
- deliberate quiet/dark UI reserve;
- no named real district, landmark, road, transit route, address, business, political institution or real geography.

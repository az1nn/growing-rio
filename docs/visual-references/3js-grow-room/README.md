## Candidate synthesis for DA LATA

The 3JS-002 grow room should test a **3D diorama rendered with pixel-art discipline**:

- fixed orthographic / near-isometric camera;
- low-poly, chunky geometry and readable silhouettes;
- deliberate prop clusters rather than empty prototype space;
- restrained pixel-informed surface detail instead of texture noise;
- miniature depth cues, but no blur over interactive/focal content;
- darker room envelope with warm practical focal light and cooler fill;
- strong foreground / work-zone / background layering;
- portrait-first readability behind the product UI.

This direction remains **CANDIDATE** until the grow-room rendered acceptance gate passes.
